Per-game launcher backgrounds live in this folder:

- WoW Forever Beta: `wow_forever_background.png`
- Retail: `wow_midnight_background.png`
- Classic Era: `wow_classic_background.png`
- Mists of Pandaria Classic: `wow_mop_classic_background.png`
- TBC Anniversary: `wow_tbc_anniversary_background.png`

PNG, JPG, JPEG, WEBP, and BMP are supported. Images are cropped to the window and crossfaded when the selected game changes. Missing files use the shared `image.png` fallback.
